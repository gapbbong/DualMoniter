================================================================
          CIM PRO v3.2 실시간 모니터링 시스템 사용 안내
================================================================

이 시스템은 교실 내 24대 PC의 듀얼 모니터 화면을 실시간으로 관리하는 시스템입니다.
처음 오신 선생님께서는 아래 순서대로 실행해 주세요.

1. [01_듀얼모니터_교사_대시보드_실행.bat] 파일을 더블 클릭합니다.
   - 검은색 콘솔 창이 뜨면서 서버가 시작됩니다. (창을 끄지 마세요!)
   - 자동으로 인터넷 브라우저가 열리며 대시보드가 나타납니다.

2. 학생들에게 파일을 전송합니다.
   - 마에스트로(Maestro) 또는 파일 전송 프로그램을 사용하여 
     [02_학생용_모니터링_에이전트_전송용.exe] 파일을 모든 학생 PC로 보냅니다.
   - 전송 시 '전송 후 바로 실행' 옵션을 선택하시면 자동으로 연결됩니다.

3. 대시보드 확인
   - 학생 PC가 연결되면 대시보드에 실시간 화면(좌/우)이 나타납니다.
   - 우측의 [ < ] 화살표 아이콘을 누르면 시스템 로그와 개별 PC 상세 정보를 볼 수 있습니다.

4. 종료 방법
   - 관리 종료 시 실행했던 검은색 콘솔 창을 닫으시면 됩니다.
